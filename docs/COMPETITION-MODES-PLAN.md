# 题型、资源与比赛规则改造

状态：功能实现及隔离测试已完成。最终规则见 [比赛规则](COMPETITION-RULES.md)，部署与验收以 [验证记录](VERIFICATION.md) 为准。

## 已确认的需求

- 题目编辑按配置标签组织，保留跨标签草稿，保存时定位无效字段。
- 动态计分展示与实际算法一致的分数曲线；提示独立增删、排序，支持多行内容。
- 题型与资源分开：客观题、CTF、AWDP、AWD。客观题包括填空、单选、多选。
- 静态文件、专属附件生成器和靶机分别配置，不能继续用资源组合充当题型。
- 题库管理启用和练习可见性；定时出题由比赛与题目的关联记录管理，不能影响同题在其他比赛中的状态。
- 客观题与实操题分别配置时间。支持固定起止时间，或在有效窗口内主动开始、按限定时长作答。
- 用户已确认：AWDP 上传补丁包，由平台构建和检查；自由开始按报名战队共享计时。
- 用户已确认本次也实现完整 AWD 对抗赛，不能把 AWDP 补丁判题称作已实现 AWD。

## 分层设计

题库保存题目内容、判题方式、提示、资源模板。比赛保存赛制、报名分组、各题上线时间、客观/实操时间配置与计分规则。参赛记录保存战队开始时间、截止时间与提交记录。资源实例保存独立配置快照与截止时间，不能通过更换题型或重复开始延长作答。

后台题目标签按类型显示：题目内容、答案与计分/Flag 与计分、附件、靶机、AWDP 判题、发布设置。只展示当前题型需要的参数，配置不分散到重复的侧栏或弹窗。比赛后台按基本信息、题目安排、时间规则、报名分组组织。

## 客观题

单选使用单选控件，多选使用复选控件，填空按空位呈现输入框；和 Flag 提交区分别实现。答案只在管理员接口返回，公共题目、列表、榜单、错误响应均不得包含正确答案。单选按选项 ID、多选按无序选项集合、填空按每空的允许答案匹配。编辑已作答题的判题规则受保护，历史分数不能被静默改写。

## 比赛时间

客观题与实操题分为两个阶段，各自可继承比赛时间或配置固定/自由开始规则。自由开始以服务器时间写入战队记录，重复或并发开始返回同一次记录；实际截止为开始时间加时长与窗口结束两者的较早值。未开始前不泄露题面，截止后禁止提交、生成附件和启动/续期环境。直接 URL、附件下载和资源操作均检查作答阶段。榜单和动态只公开已经上线的题名及比赛信息，不返回未上线题面或答案。

## AWDP

攻击验证和防守验证分别记录。补丁包使用受限归档格式；只允许普通相对路径文件，限制大小、数量和展开总量，不允许软链接、硬链接、路径穿越或用户指定 Dockerfile。管理员提供基础镜像、补丁应用位置和检查镜像，平台创建隔离构建/测试任务，执行功能检查与漏洞检查，分别呈现结果。运行选手修复代码的环境不持有 Docker socket、数据库凭据、平台文件或检查脚本。检查任务有资源配额、执行超时、幂等结算和失败回收。

AWDP 与 AWD 的比赛计分必须区分：国内部分 AWDP 赛事采用分轮自动攻击与补丁防御积分，AWD 则需要战队服务持续运行、Flag 轮换、攻击提交、服务可用性巡检与逐轮结算。赛制名称、题型能力和真正运行的判题流程必须一致，不能只新增一个类型选项。

## 赛制定案

采用[第十八届国赛决赛公开规则](https://www.ciscn.cn/announcement/view/388)中的无轮次 AWDP：攻击和修补各为独立计分单元，只能各完成一次，可分别动态衰减。资料核对确认早期赛事存在轮次式 AWDP，故不把两种规则混用。

AWD 独立采用统一比赛时钟、Flag 轮换与有效轮数、服务功能检查、攻击去重和轮次结算。参考 [FAUST Gameserver](https://github.com/fausecteam/ctf-gameserver) 的控制器/检查器/提交/排行榜职责分离，以及 [FAUST 官方运行说明](https://2026.faustctf.net/information/setup/) 的服务状态与有效 Flag 处理。AWD 需要同时对抗，实操阶段不提供战队自由开始；客观题阶段仍可单独设置。

## 混合选题与比赛计分覆盖（用户最新确认）

比赛不按 CTF/AWDP 限制题目集合，可混合选择客观题、CTF 与 AWDP；AWD 也作为有专属运行能力的题目模板，所需对抗参数只在包含此类题时显示。题库的分值是默认值，比赛关联记录可覆盖分值、动态衰减与小题积分，并支持多轮结算。覆盖值只作用于当前比赛。

默认沿用题库的解题计分；可选固定分、动态分、轮次分。无轮次 AWDP 使用攻击/防守两个独立计分单元；配置轮次计分后，以每轮结束时已完成的攻击/防守记录结算，重复任务不重复得分。AWD 基于当轮有效攻击、服务检查和防守状态结算。所有轮次积分落持久化明细，以当轮配置和结果为依据，避免重启或重试重复加分。

客观题默认固定分；支持比赛覆盖分值。动态和多轮规则只应用于支持这些规则的实操题。启用任意轮次计分时实操阶段必须有统一时钟，不能让不同战队处于不同轮次；无轮次实操与客观题阶段支持窗口内自由开始。
