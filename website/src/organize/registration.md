# 报名、分组与权限

报名设置负责决定谁能进入比赛、需要提交什么资料，以及不同组别可以做什么。比赛可见性和参赛资格是两层设置，应分别配置。

## 参赛范围

公开比赛允许用户查看公开信息；私密比赛仅向管理员、指定战队及符合条件的已有报名成员开放。私密比赛需要选择指定战队。

报名可向所有符合条件的战队开放，也可要求邀请码或限定战队。设置报名窗口后，队长只能在该时段提交报名。队伍人数、重复参赛、组别开放状态和审核要求仍会检查。

## 默认组别与自定义组别

每场比赛都有一个不能删除的默认组别，作为比赛基础权限。需要区分正式队、体验队等参赛范围时，添加自定义组别，在弹窗内设置名称、权限和邀请码。

已有战队报名后，仍可增删自定义组别。删除组别时，原报名战队会回到默认组别，因此删除前应核对默认组别权限。

| 权限 | 作用 |
| --- | --- |
| 报名 | 是否允许继续选择这个组别报名 |
| 查看、作答、资源 | 是否可见题目、提交答案和使用题目环境 |
| 计分、三血、动态衰减 | 是否参与对应的积分计算 |
| 全局排名 | 是否出现在全局排行榜 |

组别可以覆盖单题权限。开赛后计分相关权限会锁定，不能通过调整组别重算正式成绩。

## 邀请码

比赛邀请码控制比赛报名。自定义组别设置独立邀请码后，选择该组时使用组别邀请码；未设置时沿用比赛规则。默认组别使用比赛设置。

组别邀请码不替代指定战队范围、队伍人数或审核。不要把战队邀请码发给需要报名比赛的人，战队邀请码用于加入队伍。

## 报名表单与审核

在报名表单中添加字段，选择「每队一份」或「每位成员」，设置必填、选项和顺序。可使用单行、多行、单选、多选等字段，也可添加姓名、邮箱等常用资料。用预览检查后保存。

比赛可要求报名审核，组别也可覆盖审核方式。队长提交后，在比赛管理的「报名战队」展开队伍，查看资料和成员名单，再通过或退回。退回时填写可操作的修改原因。

修改表单不会重写已经提交的资料。需要队伍补充新字段时，应退回后让队长重新提交。暂停参赛用于中止已有资格，不等同于退回报名。
