# 创建一场比赛

题库保存题目，比赛选择题库中的题目并配置本场规则。先完成出题和测试，再创建比赛，可以减少发布前反复修改。

## 准备赛题

在「管理中心 → 题目」准备题面、答案、附件和环境。容器镜像需要在 Runtime 所在主机就绪，保存题目后启动测试靶机检查入口及 Flag。

尚未公开的比赛题目不要开启「开放练习」。比赛可以选用练习题，但练习成绩不计入本场比赛。

## 建立比赛

进入「管理中心 → 比赛」，新建比赛并填写名称、说明和时间。先保存，再上传海报。海报不是发布比赛的必要条件。

比赛编辑按以下顺序设置：

| 页面 | 要完成的配置 |
| --- | --- |
| 基本信息 | 名称、说明、启用状态、观战和赛后练习 |
| 赛题设置 | 选题、排序、上线安排、单题计分和限制 |
| 时间规则 | 比赛时间、客观题与实操题的作答方式 |
| 报名设置 | 参赛范围、报名窗口、组别和附加表单 |
| 资源限制 | 每队每题开启次数、每队及全场并发上限 |
| WriteUp 提交 | 提交窗口、提交人、文件要求 |

## 选择题目

在「赛题设置」点击「调整选题」，通过弹窗搜索和筛选题库。确认后回到赛题列表，调整顺序并展开需要单独设置的题目。

题目可以沿用题库分值，也可以覆盖本场分值。设置定时上线时，选手要到指定时间才看到该题。修改后点击「保存」，切换标签页本身不会提交配置。

## 发布前检查

用普通账号创建测试战队，按预期组别报名，检查审核、题目可见性、计时和资源操作。测试静态 Flag、动态 Flag、多小题及补丁提交时，应使用隔离的测试比赛。

核对比赛说明与页面中的时间、计分和权限一致，再启用比赛。开赛后，赛题集合、时间和计分核心规则会锁定；需要临时通知时使用比赛公告。
