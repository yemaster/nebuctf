# 比赛期间与赛后

比赛发布后，常用操作集中在比赛管理入口。处理报名、环境异常和报告时，先确认当前比赛和战队，避免对同名内容操作。

## 报名与参赛资格

在「报名战队」筛选待审核队伍，展开查看成员及表单资料后处理。需要补充资料时退回；已有资格需要临时中止时使用暂停参赛，处理后可以恢复。

取消组别报名权限不会自动撤销已有报名。变更已有资格应从报名管理处理。

## 公告、提示与上线

通过公告发布规则补充和服务通知。题目提示应写入对应题目，选手可在比赛动态中收到新提示提醒。定时上线、手动启停赛题和权限变更都会影响选手可见内容。

已有提交或活跃环境的题目不能任意修改判题参数。需要更换镜像或答案时，先确认冻结规则，避免让已经分发的环境与新答案不一致。

## 环境与提交监控

在资源管理查看排队、运行、失败和回收状态。排查顺序是 Runtime 健康、镜像就绪、配额、服务健康检查和入口网络。不要通过放宽特权或关闭隔离来解决普通镜像配置问题。

提交记录可用于核对判题。动态 Flag 的跨队提交线索需要管理员进一步核实，线索本身不等于已经完成判罚。流量采集需事先配置并按授权访问，详见[系统设置](../reference/settings)。

## 收集与审核 WriteUp

在比赛编辑的「WriteUp 提交」启用收集，设置提交人、开放窗口、允许格式和大小。截止时间必须填写；开始时间留空时，从比赛结束开始接收。

「WriteUp 管理」可按组别和提交状态筛选，查看报告、确认收到、退回修改或批量下载。PDF 支持同屏预览，ZIP 提供下载。退回后仍受截止时间限制，需要补交时先延长窗口。

## 开放练习与保留数据

赛后开放练习后，练习提交不改变正式成绩。内容导出可保存比赛题目与配置，但不包含选手账号、报名、提交和 WriteUp；完整归档仍需要[数据库与文件备份](../deploy/maintenance)。
