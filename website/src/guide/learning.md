# 练习与学习

练习场面向个人训练，成绩与比赛分开记录。已经在练习场完成的题目，不会自动计入后来参加的比赛。

## 题库与题单

在练习场按分类、难度或关键词查找题目。打开题目后，题面、附件、靶机和答案提交位于同一工作区。

题单将一组题目按训练目的组织起来。可以从题单连续练习，也可以回到题库选择其他题目。多小题显示分别完成的进度，全部通过后才算整题完成。

## 教程与技能树

教程记录阅读进度，技能树将文档和练习关联到节点。先完成前置节点，再继续后续学习。阅读文档和解题是不同的完成条件，应查看节点中要求的内容。

## 赛后练习

管理员开放赛后练习后，符合访问条件的用户可以继续进入比赛题目。赛后练习不改变正式比赛成绩，也不使用正式比赛的提交与开启次数额度。

练习仍受站点资源池、环境数量和操作冷却限制。题目资源被停用或镜像不可用时，需要管理员恢复环境。
