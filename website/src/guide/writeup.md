# 提交 WriteUp

开启 WriteUp 收集的比赛，会在比赛菜单提供提交入口。每支战队共用一份报告，是否允许队员提交由管理员设置。

## 准备报告

查看提交开始时间、截止时间、文件格式、大小上限和内容要求。平台支持 PDF 或 ZIP，赛事可以只允许其中一种；实际限制以提交页面为准。

PDF 适合直接预览。选择 ZIP 时，将 Markdown、图片及其他要求的材料放入同一个压缩包，保持相对路径可用。

## 上传与替换

在开放窗口内选择文件并上传，等待完成后确认文件名和提交状态。允许替换时，再次上传会更新本队的同一份报告。

若队友刚提交了新版本，页面会要求刷新后再操作，避免覆盖未看到的内容。仅队长可提交的比赛中，其他有权成员仍可以查看本队报告和反馈。

## 查看反馈

管理员可以确认收到，或退回并填写修改意见。退回不会自动延长截止时间；需要在原截止时间内重新提交，或者由管理员调整窗口。

「必交」是赛事的报告要求，不会自动改变题目得分。具体评审和补交安排以比赛公告为准。
