# 账号、战队与报名

练习场按个人记录成绩，比赛按已报名战队记录成绩。同队成员共享比赛中的答案进度和独立靶机。

## 注册与登录

在平台注册账号，填写用户名、邮箱和密码。若站点启用了邮箱验证，按邮件提示完成验证。登录时可以使用用户名或邮箱。

账号设置中可以修改资料、头像和密码。修改密码会撤销已有会话，需要重新登录。

## 创建或加入战队

打开「我的战队」，创建一支队伍，或者使用队长提供的战队邀请码加入。战队邀请码用于加入战队，与比赛或组别的邀请码用途不同。

队长可以管理成员、更新战队 Logo、重置邀请码和转让队长。报名一场未结束的比赛后，成员变更会受到限制；先确认队员齐全，再提交报名。

## 报名比赛

1. 打开比赛详情，查看起止时间、队伍人数和报名要求。
2. 由队长点击报名，选择自己的战队和组别。
3. 按要求填写邀请码、战队资料和成员资料，提交报名。
4. 若需要审核，在比赛详情查看状态；退回后按原因修改并重新提交。

一名成员不能通过多支战队重复参加同一场比赛。加入了多支队伍时，应确认本次选择的参赛战队。

选择的组别设置了邀请码时，填写该组的邀请码；组别未设置时，按比赛的报名规则执行。私密比赛还要求战队在管理员指定的范围内。

## 报名之后

审核通过且进入作答时段后，可以进入赛场。开赛前，队长可在允许的情况下取消报名；开赛后不能自行取消已通过的报名。参赛资格被暂停时，联系赛事管理员处理。

有附加表单时，未提交的填写内容会保存在当前浏览器草稿中。草稿不会跨设备同步，清理浏览器数据也会删除它。已提交的报名资料以当次记录为准。
