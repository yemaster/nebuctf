# 答题与靶机

进入比赛后，从题目目录选择赛题。看不到预期的题目时，先查看上线时间、组别权限和前置条件；部分题目需要完成其他题目后才会出现。

## 提交答案

CTF 题在 Flag 输入框提交答案。Flag 区分大小写，空格也参与校验，复制时不要额外添加字符。多小题共用提交入口，平台匹配对应的小题并记录进度。

客观题在答卷内作答，由战队共享进度和计时。最终提交后，全队不能继续修改该份答卷。提交前确认答案及剩余时间。

比赛可能限制提交次数，或设置互斥题组。互斥组在首次正式提交受理后确定路线，错误 Flag 也可能选定路线；先读清比赛说明再提交。

## 启动环境

在题目「靶机」区域点击启动。排队或创建期间等待状态更新，运行后使用显示的访问地址：HTTP 题打开链接，nc 题可以通过网页终端连接。

同队成员共用一个比赛环境。公共靶机由管理员启动，普通选手直接使用。专属附件使用「生成附件」，完成后下载题目文件。

## 次数与时长

设置开启次数限制的题目会显示「还剩 X 次开启」。创建成功扣一次，失败不扣，重开会扣次数；多容器整组启动计一次。用完后不能再开启，已经运行的环境仍可在有效期内使用。

续期增加可用时长，不扣开启次数，但仍受平台续期上限和比赛截止时间限制。停止环境会回收本组容器；需要保存的解题材料应先下载到本地。

环境数量、CPU 或内存不足时，按页面提示等待或释放不再使用的环境。操作冷却和开启次数是不同的限制，冷却结束不会补回已消耗的次数。

## 提示与比赛动态

题目提示可能需要扣分，确认购买前查看代价。比赛动态会显示题目上线、新提示和公开解题事件。封榜期间，公开分数及解题信息可能暂时停止更新，以比赛规则为准。
