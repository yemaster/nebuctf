# 导入与导出

内容包用于迁移题目和比赛配置。它不会替代数据库备份，也不会迁移运行中的环境。

## 导出内容

在题目或比赛列表、编辑页点击导出，下载 NebuCTF ZIP 包。

题目包包含题面、判题配置、小题、提示、资源配置和静态附件。比赛包还包含选题、上线安排、计分、分组、报名表单、资源限制、观战和 WriteUp 设置。

镜像只保存引用和配置，不包含 Docker 镜像文件。选手账号、报名、提交记录、成绩及选手 WriteUp 不进入内容包。导出包包含答案和检查配置，应按出题资料保管。

## 导入流程

1. 在管理列表点击「导入」，选择 NebuCTF ZIP 包。
2. 等待校验，核对题目、类型、小题和附件。
3. 导入比赛时选择未来开赛时间；相关时间会按相同偏移量调整。
4. 确认导入，进入新条目编辑页，补齐镜像和报名配置。
5. 测试后再启用题目或发布比赛。

导入会创建新 ID，不覆盖已有题目和比赛。单独导入的题目默认未启用，比赛默认未发布。

## 跨站迁移

静态 Flag 使用站点密钥校验，平台不保存明文。导入到不同密钥的站点时，需要按页面提示重新填写答案。动态模板和客观题答案可以随配置迁移。

指定参赛战队需要重新选择。邀请码跨站需要重新设置；不要为了省略这一步而将源站密钥分发给其他平台。

## 文件限制

文件格式为 `nebuctf-content`，版本 1。每包最多 200 道题，上传最大 256 MiB。预览有效期为 15 分钟，确认前应完成所需补充。

当前不兼容 GZCTF 或 CTFd 的原生导出包。需要从其他平台迁移时，应按 NebuCTF 的题目配置重新整理，并实际验证判题、分值与环境行为。
